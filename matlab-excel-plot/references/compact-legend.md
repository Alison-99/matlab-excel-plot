# 紧凑图例实现与验证

- 默认保留已有字体及8pt字号、常规字重、单列，以及各方法排序和符号。先测量原生ItemTokenSize=[30 18]高度，再调整为[16 max(6,FontSize)]并测量。ItemTokenSize控制标记区域，不能保证或宣称精确改变文本基线间距；不使用未公开的EntryContainer等内部属性。
- 通过公开text.Extent测量每个标签的真实宽高（使用相同字体、字号和解释器），单行标签用字号与标记直径的较大值加1pt作为行距（Extent含字体行框留白，不将其全部用作可见字形间距）；多行标签采用实测完整高度加1pt。上下及左右内边距1.5pt，样本长度16pt，样本与文字间距2pt。自动按标签长度计算宽度，不假定所有标签都是短英文。
- 原生调整后高度若仍大于实测紧凑高度10%，使用公开axes/line/text构成白底有边框覆盖层，Tag=CompactLegend。保留隐藏的原生legend及PlotChildren/String用于排序和重建，不修改绘图数据。覆盖层保持原始线宽和标记大小，字体大小不变。
- 记录CompactMetrics：原生默认/调整后/最终高度、行距、字号、是否回退、位置和遮挡状态。单图和所有tile布局完成后各运行一次；汇总图从未扩展的LegendBaseYLim重新判断，防止重复扩大纵轴。改尺寸、改标签后应重新调用place_compact_legend，不能假定覆盖层像原生legend一样自动重排。
- 覆盖层使用normalized定位以跟随画布，重新布局/缩放并导出前必须重新排版。复制或筛选数据轴时排除CompactLegend；不要把覆盖层当成第二组数据。PNG、矢量PDF、FIG均验证，重开FIG检查文字和元数据。
- 验证至少2、4、6、8条目，增加较长标签；确认字号不变、最终高度比默认明显减小、文字实际渲染字形互不相交且位于边框内；检查长标签水平Extent不越界，不把包含字体行框留白的Extent当作字形墨迹边界、标签与线型对应正确、曲线线段和标记不被遮挡。多行文字或超长标签按实测尺寸排版，若图框容纳不下，报告并调整画布，不无限扩大Y或隐藏条目。
