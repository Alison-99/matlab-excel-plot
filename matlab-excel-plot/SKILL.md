# MATLAB Excel 绘图

默认中文沟通。用户只提供Excel即可，复用内置 [scripts/plot_excel.m](scripts/plot_excel.m)。用户最新提供的r.m是线型和字体样式来源：黑色曲线，基础样式线宽0.5，ARL1默认线宽为0.8pt、默认标记大小6、坐标轴线宽0.8、刻度字号7，轴标签按MATLAB默认倍率约7.7号，图例8号宋体、常规字重，默认紧凑排版（保持字号，通过布局压缩间距）。前四条线型为-s、--o、:^、-.x，继续沿用参考代码的-+和-.*扩展更多曲线。用户另行指定时优先遵从。

## 识别工作簿

1. 使用指定文件；未给路径时只在当前目录有限查找，忽略 `~$` 文件。读取所有工作表名称、非空范围、表头、实验说明和代表性数据。可用 MATLAB 的 `sheetnames`、`readcell`，或现有本地工具预览，最终用 MATLAB 作图。
2. 按表头、Case、场景和参数识别二维数据块；允许横向并排和纵向堆叠。找出每块真正的 X 列及 Y 曲线，不固定为前两列，不沿用上次的列号、工作表编号或行数。优先使用工作表名称。
3. 图例来自表头：方法名直接使用；多级表头中参数名和数值组合为 `r=0.1` 等，不能把 r 自行写为 lambda。每个 plot 仅标注对应的 `Case N`；场景、维度等只用于文件名或交付说明，不放在图顶部。相同场景标签但数值不同的块，按源行号或 block 编号分开，不擅自合并或改名。
4. ARL1 依据实验上下文与偏移量识别，不能只凭数值大小。不要混入 UCL、SDRL、SE、耗时、原始观测或监控统计量。零偏移是基准行，默认与 ARL1 曲线一起保留并说明；不把它描述为非零偏移结果。重复复制区域优先使用含完整 X、表头和 Case 的主数据块。
5. 仅给 Excel 且实验块含义清楚时，对所有明确的有效结果块逐块出图；排除明确标注“未用”的块，除非用户指定。简要报告识别结果后执行，不再要求指定 .m。若有多种无法区分的结果含义或未知 X，先列出候选并询问。明确部分可以先处理；不要自动给数百个不明块套模板。

## 生成配置，复用绘图代码

- 读取 [references/configuration.md](references/configuration.md) 配置说明。在每次独立输出目录复制内置 `plot_excel.m` 、排序辅助函数 `legend_curve_order.m` 、图例避让函数 `place_compact_legend.m` 和 `arl1_line_width.m`，生成 `run_plots.m`，设置绝对 Excel 路径、jobs 和输出目录，再调用函数。保存两者便于脱离技能重跑，不修改技能模板来适配某次数据，也不覆盖已有结果。
- 一个 job 对应一个实验块/Case；每条曲线指定确切的 Excel Y 范围及相应 X 范围。由 Excel 读取实际 X，不能仅按行数用 linspace 或旧步长构造。不同曲线采样数量不同时用各自 xRange；不能填造数据让长度一致。
- 支持任意合理曲线数量。四条曲线沿用原线型，更多曲线继续分配不同的线型与标记；用户指定时通过 lineSpecs 配置。不要把实验种类误当线型，图例必须对应实际曲线。
- ARL1 默认沿用用户既有的 `log10` 变换，标签写 `log10(ARL1)`；其他指标按含义选择原值或用户要求的变换，不给已经取对数的数据重复取对数。
- X范围来自实际数据；默认在横轴显示全部实际X取值，包括左右端点，不自动抽稀或省略标签。若密集，优先调整画布或标签角度，不能未经用户要求删减刻度。Y 默认自动范围；用户需要统一比较范围时覆盖全部数据，不机械使用旧的 `[0,2.5]`。单位只使用已知信息。
- 缺失保留为 NaN 间断，报告受影响行数；不补零、不默删异常值、不擅自平滑、插值、拟合、排序或聚合。非正 ARL、无法解析的文本或不匹配的 X/Y 应排查并说明，不能蒙混导出。
- 内置函数面向数值实验曲线；日期、分类轴或误差条等超出接口的需求，复制后作必要适配，保留用户原意。额外数值绘图参考 [references/matlab-patterns.md](references/matlab-patterns.md)。

## ARL1 曲线专用线宽

- 当前用户指定ARL1默认LineWidth=0.8pt，包含log10(ARL1)。取消此前2.5pt默认值及增加30%的规则，不能因旧宽度较大而自动加粗。
- 内置 [scripts/arl1_line_width.m](scripts/arl1_line_width.m) 统一返回0.8；须随绘图脚本复制。plot_excel通过yLabel中的ARL1识别，混合指标可用job.arl1Mask逐条区分。其他指标保留job.lineWidths或原始宽度，用户明确指定新值时优先遵从。
- 仅调整ARL1图形对象的LineWidth，保留颜色、线型、数据点标记、字体、坐标轴、图例和Case布局；图例样本仍使用LegendOriginalLineWidth记录的基础宽度。汇总及重复导出不再改动线宽。

## 当前样式来源与导出

- 以本次用户提供r.m中的实际设置为准，替代此前多次试验的大字号、粗曲线样式。标记及其他属性保持参考样式；ARL1曲线线宽固定为0.8pt，图例样本仍保持基础线宽。
- 图例FontSize=8、FontWeight=normal，不通过缩小字体实现紧凑。先使用原生legend的ItemTokenSize=[16 max(6,FontSize)]及NumColumns=1，再测量实际高度；原生最小行距仍过大时才回退到公开axes/line/text对象组成的CompactLegend覆盖层。优先宋体/SimSun，本机若无则用Songti SC；仍无时使用可用替代字体并说明。
- Case20号及原有字重、4图2行2列/6图3行2列、无总标题、图例上下排序和避让逻辑继续保留。字体修改不改变数据含义，不复制r.m里固定[0,2.5]纵轴范围而裁掉其他数据。
- 默认白底900dpi PNG、矢量PDF和可编辑FIG；默认画布宽24cm，单图高18cm，汇总图每行高11cm。按输出实际尺寸目视核对。

## 图题和 Case 排列

- 每张单图或子图的标题只写对应的 `Case 1`、`Case 2` 等，不添加工作表名、分布表头、场景、维度或指标总标题。整张汇总图顶部不加总标题。
- 4 个 Case 用 2 行 2 列；6 个 Case 用 3 行 2 列。均按 Case 编号从左到右、再从上到下排列；原表是两排三列也要重排为三排两列，编号含义保持不变。
- 多 Case 默认同时交付单图和汇总图。复制并调用 [scripts/combine_case_plots.m](scripts/combine_case_plots.m)，复用源图的坐标和已排序图例，避免另写汇总代码漏掉本规则。其他 Case 数量用两列及足够行数，除非用户指定布局。

## 默认紧凑图例与遮挡判断

- 单图及汇总图都调用 [scripts/place_compact_legend.m](scripts/place_compact_legend.m)，保持r.m的8号字体和原线型、符号，单列、图框内部显示。详细实现及验证见 [references/compact-legend.md](references/compact-legend.md)。
- 完成字号、坐标及布局后drawnow，检查最终显示图例包围框是否遮挡曲线线段或符号。优先右上角；遮挡时保持纵轴下界，仅向上扩展上界，按原跨度15%、30%、50%、75%、100%尝试。仍不行时恢复原纵轴范围并放左下角。不能移到图外或改两列。明确固定范围时跳过扩展。
- 汇总图全部tile完成后重新执行判断。避免无限扩大压扁曲线；仍有遮挡应报告并人工调整。保留图例排序，绝不修改实际ARL数值。

## 图例顺序

- 每张图的图例从上到下与曲线整体从上到下对应；不按 Excel 列序、绘制顺序或只看最后一个点排序。复用 [scripts/legend_curve_order.m](scripts/legend_curve_order.m)，绘图函数已调用它。
- 曲线交叉时，逐对比较共同的有效实测 X 点：哪条曲线位于上方的点更多，其图例就应在上方；下方点更多则在下方。数值相等或近乎重合的点不投票。以采样点数为“多”的默认口径，不按曲线面积、均值或偏移区间长度推断。
- 多数关系能形成一致顺序时全部满足；出现 A 高于 B、B 高于 C、C 高于 A 的循环时，按净胜场、上下位置投票优势比例总和打破循环，并在运行日志说明。完全重合或无可比数据则保留稳定的原始顺序。不同 X 采样只比较共同实测点，不为排序插值；重复 X 须先核对其含义。
- 只重排图例句柄与标签，不重新分配方法线型或改变曲线数据。同一方法跨 Case 保持线型一致，但图例顺序可随各 Case 的曲线位置变化。汇总图也应沿用各子图排好序的图例，不能重新按原始标签数组排列。

## 运行与核对

- 定位本机 MATLAB。本机已验证的命令为 `/Applications/MATLAB_R2023b.app/bin/matlab -maci64 -batch "run('绝对路径/run_plots.m')"`：当前安装是 Intel 版本，在本机默认选择 maca64 会失败。先核对安装目录及架构，不能在其他机器盲用此路径或架构。
- 正确处理 shell 路径及 MATLAB 单引号转义。运行 `run_plots.m`，每图导出 900 dpi PNG 和可编辑 FIG；按需增加汇总图或 PDF。中文图题选择 `listfonts` 中可用的中文字体。
- 检查 MATLAB 退出状态、导出文件非空、各曲线有效点数、图例和源范围；打开图片检查坐标、裁切、乱码和遮挡。汇总图复制 axes 时先保存源轴句柄，再创建目标 tile，核对曲线和图例确实存在。
- 缺失环境、许可证或运行失败时保留已准备代码并准确说明；不能用 Python 图冒充 MATLAB 结果。交付实际图片、可编辑图及重跑脚本，链接使用绝对路径；多图可打包。简要交代数据分块、变换和基准行处理。
